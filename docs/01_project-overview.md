# RGB·열화상 Fusion 기반 태양광 구역 관리 플랫폼

> RGB, 열화상 이미지를 단일 또는 pair로 분석하여 태양광 발전소의 이상 후보 구역을 선별하고, 청소·재촬영·현장 점검·교체 검토 우선순위를 제공하는 유지보수 지원 플랫폼
> 
> 
> RGB 또는 열화상 단일 이미지만 있는 경우에는 단일 모달 모델로 분석하고, 동일 구역의 RGB·열화상 pair가 제공되는 경우에는 Fusion 모델로 분석하여 이상 후보 선별 정확도를 높인다.
> 

---

## 1. 문제 정의

태양광 발전소는 넓은 구역에 다수의 패널이 설치되어 있어 모든 패널을 자주 정밀 검사하기 어렵다. 따라서 핵심은 개별 패널 정밀 진단보다 **구역 단위 이상 후보를 빠르게 선별하고 결과를 누적 관리하는 것**이다.

1. **RGB·열화상 pair 기반 보완 분석이 필요함**
    - RGB: 오염, 낙엽, 음영, 식생 침범, 외관 손상 확인
    - 열화상: 핫스팟, 과열, 비정상 발열 확인
    - RGB-Thermal pair: 외관 이상과 발열 이상을 함께 확인하여 단일 이미지로 놓칠 수 있는 이상 후보를 보완 확인
2. **이상 결과를 실제 조치로 연결하기 어려움**
    - 이상 탐지 결과를 청소, 재촬영, 현장 점검, 교체 검토로 분류할 기준이 필요하다.
3. **긴 점검 주기 때문에 변화 추적이 필요함**
    - 이전 점검 대비 이상 면적, 심각도, 반복 발생 여부를 비교해야 한다.

---

## 2. 서비스 목표

PV-Insight의 목표는 RGB·열화상 이미지를 단일 또는 pair로 분석하여 관리자가 **우선 확인해야 할 구역**과 **필요한 유지보수 조치**를 빠르게 판단하도록 지원하는 것이다.

1. **구역 단위 점검 관리**
    - 발전소, 구역, 패널 그룹 단위로 관리한다.
    - 이미지별로 구역 ID, 촬영 시점, 점검 회차, 촬영 방식을 연결해 저장한다.
    - 동일 구역의 RGB·열화상 이미지가 함께 제공되는 경우 pair로 연결해 저장한다.
2. **RGB·열화상 단일/Pair 기반 이상 분석**
    - RGB 단일 이미지는 RGB-only 모델로 외관 결함과 오염을 분석한다.
    - 열화상 단일 이미지는 Thermal-only 모델로 발열 이상과 핫스팟을 분석한다.
    - RGB-Thermal pair가 제공된 경우 Fusion 모델로 외관 이상과 발열 이상을 함께 분석한다.
3. **조치 후보 및 우선순위 제공**
    - 청소 후보: 오염, 먼지, 낙엽, 조류 배설물
    - 재촬영 후보: 흐림, 반사, 과노출, 저신뢰도
    - 현장 점검 후보: 핫스팟, 과열, 반복 이상, 외관 이상과 발열 이상 동시 발생
    - 교체 검토 후보: 심각한 외관 손상, 넓은 열 이상, 반복 악화 패턴
4. **정기 점검 이력 및 변화 추적**
    - 구역별 이상 발생 횟수, 면적 변화, 심각도 변화, 반복 발생 여부를 관리한다.

## 3. 핵심 차별점

| 차별점 | 설명 |
| --- | --- |
| 구역 단위 관리 | 개별 패널보다 발전소 구역 단위 이상 후보 선별에 집중 |
| RGB-Thermal pair 분석 | RGB와 열화상 이미지를 함께 활용해 단일 이미지보다 더 정확한 이상 후보 탐지 가능 |
| 단일·Pair 입력 지원 | RGB 또는 열화상 단일 이미지만 있어도 분석하고, 두 이미지가 함께 있으면 Fusion 모델로 분석 |
| 조치 중심 결과 | 정상·이상 판정이 아니라 유지보수 조치 후보 제공 |
| 변화 추적 | 구역별 반복 발생, 악화 여부, 심각도 변화 관리 |
| 대시보드 관리 | 이상 구역, 조치 유형, 심각도 분포를 한 화면에서 확인 |

## 4. MVP 범위

| --- | --- |
| 사용자 인증 | 로그인, 사용자 권한 구분 |

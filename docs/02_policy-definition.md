# 정책 정의서

## 1. 문서 개요

**RGB·열화상 기반 태양광 구역 관리 플랫폼**의 사용자 권한, 데이터 관리, 이미지 업로드, AI 분석, 결과 산출, 예외 처리, 네트워크/API 접근, 인프라/배포, 운영 보안, Frontend 화면 처리 기준을 정의한다.

플랫폼은 RGB 이미지와 열화상 이미지를 각각 단건 분석해 태양광 발전소의 이상 후보 구역을 선별하고, 청소·재촬영·현장 점검·교체 검토 후보와 우선순위를 제공한다.

> **현재 구현 기준**
> - RGB와 열화상 이미지는 각각 독립적인 단건 분석 대상으로 처리한다.
> - Pair 생성·관리 및 Fusion 분석은 현재 운영 범위에서 제외한다.
>
> **확인 필요**
> - 발전소·구역·점검 관리 구조
> - 점검당 이미지 허용 개수
> - 이미지 위치 및 설비 연결 방식
>
> 위 확인 필요 항목은 이번 문서에서 새 기준으로 확정하지 않는다.

정책 정의서는 다음 설계와 구현의 기준으로 활용한다.

- 기능 명세서
- 사용자 권한 설계
- 화면 설계
- API 동작 기준
- 예외 처리 기준
- 네트워크 및 보안 설계
- 인프라 및 배포 설계
- 운영 및 모니터링 기준

작성 기준은 다음과 같다.

- 사용자별 데이터 및 기능 접근 기준
- 발전소, 구역, 설비, 점검 데이터 관리 단위
- RGB, 열화상 이미지의 단건 입력 및 분석 기준
- 분석 결과 저장, 시각화, 조치 후보 산출 기준
- 반복 이상, 악화 여부, 우선순위 판단 기준
- 네트워크 라우팅, API 접근, 파일 접근 제어 기준
- 운영 환경과 로컬 환경의 인프라 구성 기준
- Secret, 로그, Health Check, 장애 대응 기준
- 로딩, 빈 데이터, 오류, 잘못된 경로, 권한 없는 접근 등 Frontend 화면 상태 처리 기준

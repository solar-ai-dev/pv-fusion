# 기능 요구사항

> **현재 구현 기준**
> - RGB 이미지와 열화상 이미지는 각각 독립적인 단건 분석 대상으로 처리한다.
> - RGB 이미지는 RGB-only 모델로, 열화상 이미지는 Thermal-only 모델로 분석한다.
> - Pair 생성·조회·수정·관리 및 Fusion 분석은 현재 운영 범위에서 제외한다.
>
> **확인 필요**
> - 점검당 이미지 허용 개수
> - 이미지 위치 및 설비 연결 방식
>
> 위 확인 필요 항목은 이번 문서에서 새로운 기준으로 확정하지 않는다.

| FR-022 | 하위 설비 구조 등록 | 일반 사용자는 구역 하위에 Array, Panel, Module 구조를 등록할 수 있어야 한다. | 일반 사용자 | 필수 |

| FR-034 | 업로드 이미지 미리보기 | 일반 사용자는 업로드한 이미지를 분석 요청 전 확인할 수 있어야 한다. | 일반 사용자 | 필수 |
| FR-035 | 전체 업로드 이미지 조회 | 관리자는 서비스에 업로드된 전체 RGB, 열화상 이미지 목록과 이미지 유형, 점검 정보, 검사 대상 정보를 조회할 수 있어야 한다. | 관리자 | 필수 |

## 4. AI 분석 요청 및 처리

| 요구사항 ID | 기능명 | 설명 | 수행 주체 | 우선순위 |

| FR-049 | 전체 AI 분석 결과 조회 | 관리자는 서비스에서 수행된 전체 AI 분석 요청과 분석 결과를 조회할 수 있어야 한다. | 관리자 | 필수 |
